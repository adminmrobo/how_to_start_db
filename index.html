MySQL의 문 번호

풀이 — 그래서 MySQL은 설치하지 않는다

  1. MariaDB는 MySQL에서 갈라져 나온 프로그램이다. 명령어와 접속 방법이 거의 같다.
  2. 둘 다 기본 문 번호가 3306이다. 같이 설치하면 한쪽 번호를 바꿔야 한다.
  3. 입문 실습에서는 둘의 차이가 드러나지 않는다. 그래서 MariaDB 하나만 설치한다.
  4. PostgreSQL은 5432를 써서 MariaDB와 겹치지 않는다. 두 창고를 함께 둘 수 있다.

미션 1 — MariaDB 설치하고 접속하기

프로그램: MariaDB 12.3 LTS일상: 서랍장 창고 1호설정: 문 번호 3306

[SYSTEM] 미션 1 수신 — 첫 번째 창고를 세우고, 열쇠로 문을 열어 확인하라.

왜 MariaDB를 쓰나

문제 상황 — 표가 늘어나면 엑셀 파일 하나로는 관리가 어렵다.

앞 방법의 한계 — 파일은 한 사람이 열면 다른 사람이 고치기 어렵다. 필요한 줄만 골라 꺼내기도 번거롭다.

해법 — 표를 창고에 넣고, SQL이라는 말로 필요한 줄만 꺼낸다. MariaDB는 설치가 간단해서 첫 창고로 알맞다.

쉽게 말하면 — 서류를 책상에 쌓지 않고 이름표 붙은 서랍장에 넣는 것이다.

설치 전에 정해 둘 것 2가지

① 관리자 비밀번호 — 창고 열쇠다. 설치 중에 직접 정한다. 잊으면 다시 설치해야 하니 종이에 적어 둔다.

② 버전 — 이름 옆에 LTS라고 적힌 것을 고른다. 2026년 11월 현재 최신 LTS는 12.3이다.

옛 교안과 다른 점 — 옛 교안의 10.6.2 RC를 이 페이지에서는 12.3 LTS로 바꾼다. RC는 정식 출시 전 시험판이다.

    미션 2 — PostgreSQL 설치하고 pgAdmin으로 열기

    프로그램: PostgreSQL 18일상: 서랍장 창고 2호 + 관리 창구설정: 문 번호 5432

    [SYSTEM] 미션 2 수신 — 두 번째 창고를 세우고, 관리 창구에서 문을 열어라.

    왜 PostgreSQL도 설치하나

    문제 상황 — 분석 작업대 Orange에서 창고의 표를 바로 불러오고 싶다.

    앞 방법의 한계 — Orange가 바로 연결하는 창고는 PostgreSQL과 SQL Server 두 종류다. MariaDB는 목록에 없다.

    해법 — 두 번째 창고로 PostgreSQL을 설치한다. 문 번호가 5432라서 첫 창고와 겹치지 않는다.

    쉽게 말하면 — 작업대와 통로가 이어진 창고를 하나 더 두는 것이다.

    설치 전에 알아 둘 것 2가지

    ① 관리자 이름이 다르다 — MariaDB의 관리자는 root, PostgreSQL의 관리자는 postgres다. 비밀번호는 여기서도 직접 정한다.

    ② 함께 설치되는 것 — 관리 화면 pgAdmin이 같이 설치된다. 추가 도구를 내려받는 Stack Builder는 이번에 쓰지 않는다.

    버전 — 내려받는 곳 맨 위 줄의 최신 버전을 고른다. 이 페이지는 18을 기준으로 적었다.

      미션 3 — Orange 설치하고 첫 표 열기

      프로그램: Orange 3.40일상: 조립 블록 작업대설정: 관리자 권한 없이 설치

      [SYSTEM] 미션 3 수신 — 작업대를 놓고, 아이콘 두 개를 이어 표를 열어라.

      왜 Orange를 쓰나

      문제 상황 — 데이터를 들여다보고 싶은데 코드를 아직 모른다.

      앞 방법의 한계 — 창고는 데이터를 보관만 한다. 그림을 그리거나 무리를 나누려면 분석 도구가 따로 필요하다.

      해법 — Orange는 위젯이라는 아이콘을 화면에 놓고 선으로 잇는다. 선을 따라 데이터가 흐르고, 코드는 한 줄도 쓰지 않는다.

      쉽게 말하면 — 블록을 끼워 맞추듯 분석 순서를 조립하는 작업대다.

      설치 전에 알아 둘 것 2가지

      ① 비밀번호가 없다 — Orange는 창고가 아니라 작업대다. 문 번호도 비밀번호도 정하지 않는다.

      ② 첫 실행은 느리다 — 처음 켤 때는 준비 시간이 걸린다. 두 번째부터는 빨라진다.

      버전 — 내려받기 화면의 Windows용 기본 설치 파일을 받는다. 2026년 11월 현재 3.40.0이다.

        초파리 연구원

        창고는 세웠어. 다음은 물건을 들일 차례야. 빈 창고로는 아무것도 못 해.

        막혔을 때

        설치하다 자주 만나는 상황 다섯 가지다. 대부분 고장이 아니라 확인할 곳이 하나 있을 뿐이다.

        MariaDB 설치 중 "3306 포트를 사용 중"이라는 뜻의 경고가 나온다

        예전에 MySQL이나 MariaDB를 설치한 적이 있는 컴퓨터다. 제어판의 프로그램 목록에서 옛 프로그램을 지우고 다시 설치한다. 지우기 어렵다면 포트 칸의 숫자를 3307로 바꾸고 그 숫자를 적어 둔다.

        검은 창에 ERROR 1045 … Access denied가 나오고 닫힌다

        비밀번호가 틀렸다. 한글 입력 상태인지, Caps Lock이 켜졌는지 확인하고 다시 실행한다. 입력하는 동안 화면에 글자가 보이지 않는 것은 정상이다.

        pgAdmin에서 password authentication failed for user "postgres"가 나온다

        PostgreSQL 설치 때 정한 비밀번호가 아니다. MariaDB 비밀번호와 헷갈렸는지 적어 둔 종이를 본다.

        한글이 물음표나 깨진 글자로 보인다

        MariaDB 설치 7단계의 UTF8 체크를 빠뜨렸을 가능성이 크다. 실습 초반이라면 지우고 다시 설치하는 편이 빠르다.

        Orange가 한참 동안 열리지 않는다

        첫 실행은 시간이 걸린다. 몇 분 기다린다. 그래도 열리지 않으면 컴퓨터를 다시 켠 뒤 실행한다.
