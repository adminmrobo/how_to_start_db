## 미션 구성

| 미션 | 프로그램 | 역할 | 문 번호 | 성공 확인 |
|---|---|---|---|---|
| 1 | MariaDB 12.3 LTS | 창고 1호 (SQL 기초, 파이썬 연결) | 3306 | `MariaDB [(none)]>`가 보인다 |
| 2 | PostgreSQL 18 | 창고 2호 (Orange 연결) | 5432 | pgAdmin에서 서버 목록이 펼쳐진다 |
| 3 | Orange 3.40 | 분석 작업대 | 없음 | Data Table에 150줄 표가 뜬다 |

MySQL은 설치하지 않는다. MariaDB와 기본 문 번호(3306)가 같고, 입문 실습에서는 MariaDB가 같은 역할을 한다.

## 기준

- 운영체제: Windows
- 버전 확인일: 2026-11-12 (MariaDB 12.3 LTS, PostgreSQL 18, Orange 3.40.0)
- 설치 화면의 버튼 글자와 시작 메뉴 이름은 버전에 따라 조금 다를 수 있다.

## 설명용 모형인 것

문 번호 실험, 접속 연습 화면, 위젯 조립 연습은 실제 프로그램이 아니라 화면을 흉내 낸 연습용이다. 접속 연습에 나오는 버전 글자는 예시다.
